# RGGRP Update Expansion

## User Interface Overhaul

This update introduces a complete refresh of several core interfaces to improve navigation, accessibility, and overall appearance.

### New Settings

* Brand-new Settings frame.
* New Settings button added to the interface.
* Improved layout for easier customization.

### New Shop

* Completely redesigned Shop frame.
* New Shop button for quicker access.
* Cleaner and more organized purchasing experience.

### New Teams

* New Teams selection frame.
* New Teams button added.
* Improved team selection with a modern layout.

### New Inventory

A completely new Inventory UI and backend system has been added.

* Brand-new Inventory frame.
* Modern inventory interface.
* Improved item management.
* Better organization and performance.
* Designed to support future inventory features and expansions.

---

## Bounty System

A brand-new Bounty System has been introduced.

* Every completed bounty rewards **$5,000**.
* Designed to encourage player interaction and increase gameplay variety.
* More bounty features and balancing updates are planned in future releases.

---

## New Overhead UI

The player overhead interface has been completely redesigned.

* Cleaner name displays.
* Improved readability.
* Better organization of player information.
* Modernized appearance across all teams.
